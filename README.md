# Linea — launcher Android minimaliste (style Niagara)

## Fonctions
- Grosse horloge + date (toucher = alarmes / agenda)
- Favoris en liste verticale, en bas de l'écran (à portée de pouce)
- Barre alphabet à droite avec effet vague : glisse le doigt sur une lettre, puis glisse vers la gauche sur l'appli et lâche pour l'ouvrir
- Swipe vers le haut : toutes les applis + recherche (Entrée ouvre le 1er résultat)
- Swipe vers le bas : volet de notifications
- Appui long sur une appli : favori, monter/descendre, masquer, infos, désinstaller
- Appui long sur le vide : fond d'écran, icônes on/off, applis masquées, launcher par défaut
- Gère le profil professionnel / Dossier sécurisé Samsung

## Compiler l'APK
**Option A — GitHub (sans rien installer)** : crée un dépôt, pousse ce dossier, onglet *Actions* → workflow "Build APK" → télécharge l'artefact `Linea-apk`.

**Option B — Android Studio** : File > Open > ce dossier, puis Build > Build APK(s).

## Installer et activer
1. Ouvre l'APK sur le téléphone (autorise "sources inconnues" pour ton navigateur/gestionnaire de fichiers).
2. Au premier lancement, Linea propose de devenir l'écran d'accueil par défaut.
   Sinon : Paramètres > Applications > Choisir les applis par défaut > Écran d'accueil > Linea.
